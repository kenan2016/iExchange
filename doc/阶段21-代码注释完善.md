# 阶段21-代码注释完善

## 目标
- 补齐关键模块的中文注释，便于讲解与阅读
- 对复杂逻辑增加“为什么/怎么做”的说明

## 涉及模块
- 现货撮合与行情（撮合流程、深度/K线更新、WebSocket 推送）
- 合约交易（下单、挂单撮合、资金费率、强平触发）
- 钱包与资金流水（幂等控制、冻结/解冻/成交入账）
- 网关鉴权（JWT 校验、白名单、身份透传）

## 注释策略（建议）
- 类注释说明职责与边界
- 核心方法说明步骤与关键点
- 复杂逻辑补充“原因/意图”
- 避免逐行解释，保持可读性

## 本次补充范围

- 行情模块 DTO/模型/K线文档字段说明

### 示例二：网关鉴权过滤
**注释前（节选）**
```java
String token = exchange.getRequest().getHeaders().getFirst(TOKEN_HEADER);
if (token == null || token.isBlank()) {
    return unauthorized(exchange, "Token 缺失");
}
String key = TOKEN_KEY_PREFIX + token;
return redisTemplate.opsForValue().get(key)
    .flatMap(userId -> {
        if (userId == null || userId.isBlank()) {
            return unauthorized(exchange, "Token 无效或已过期");
        }
        return chain.filter(exchange.mutate()
            .request(exchange.getRequest().mutate().header(USER_ID_HEADER, userId).build())
            .build());
    });
```

**注释后（节选）**
```java
String token = exchange.getRequest().getHeaders().getFirst(TOKEN_HEADER);
if (token == null || token.isBlank()) {
    return unauthorized(exchange, "Token 缺失");
}
// 校验 JWT 并解析 userId
JwtUser jwtUser = jwtTokenService.parse(token);
if (jwtUser == null) {
    return unauthorized(exchange, "Token 无效或已过期");
}
// 将用户身份透传给下游服务
return chain.filter(exchange.mutate()
    .request(exchange.getRequest().mutate()
        .header(USER_ID_HEADER, String.valueOf(jwtUser.getUserId()))
        .build())
    .build());
```
