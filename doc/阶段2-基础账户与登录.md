# 阶段 2：基础账户与登录

## 目标
- 建立用户表结构
- 完成登录与 Token 发放
- 使用 JWT 作为登录凭证（无状态）
- 提供最小可用的用户信息查询

## 前置条件
- 已完成阶段 1 与 1.1
- MySQL 正常启动

## 步骤 1：初始化用户表
SQL 文件：`infra/mysql/init-user.sql`

说明：
- 如果 MySQL 容器是第一次启动，会自动执行初始化脚本
- 如果容器已存在并持久化数据，需要手动执行该 SQL

## 步骤 2：配置用户服务数据源与 JWT
配置位置：`exchange-user/src/main/resources/application.yml`

关键配置项：
- `spring.datasource.*`：连接 MySQL
- `mybatis-plus.*`：MyBatis-Plus 基础配置
- `jwt.*`：JWT 密钥、发行者、过期时间

## 步骤 3：启动用户服务
```bash
mvn -f pom.xml -pl exchange-user -am spring-boot:run -DskipTests
```

启动后会自动创建演示用户（如果不存在）：
- 用户名：`demo`
- 密码：`demo123`

## 步骤 4：登录接口
- 请求地址：`POST /api/auth/login`
- 请求示例：
```bash
curl -X POST http://localhost:18081/api/auth/login \
  -H 'Content-Type: application/json' \
  -d '{"username":"demo","password":"demo123"}'
```
- 返回示例：
```json
{
  "code": 0,
  "message": "登录成功",
  "data": {
    "token": "...",
    "userId": 1,
    "username": "demo",
    "expireSeconds": 7200
  },
  "timestamp": 1730000000000
}
```

## 步骤 5：获取用户信息接口
- 请求地址：`GET /api/auth/me`
- 请求示例：
```bash
curl -X GET http://localhost:18081/api/auth/me \
  -H 'X-Token: {登录返回的token}'
```
- 返回示例：
```json
{
  "code": 0,
  "message": "查询成功",
  "data": {
    "userId": 1,
    "username": "demo"
  },
  "timestamp": 1730000000000
}
```

## 关键实现说明
- 登录成功后签发 JWT，过期时间默认 2 小时
- JWT 为无状态方案，服务端无需保存 Token
- 密码使用 BCrypt 加密保存
- Dubbo 用户查询接口已切换为数据库查询（供其他服务调用）

- 用户信息查询接口
