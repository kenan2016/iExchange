# 阶段 6：永续合约核心

## 目标
- 支持全仓/逐仓两种保证金模式（简化）
- 支持开仓/平仓下单（限价/市价）
- 建立持仓模型与保证金账户
- 计算简化版强平价

## 前置条件
- MySQL 正常启动
- 已完成阶段 1～5 的基础环境

## 步骤 1：初始化合约表
SQL 文件：`infra/mysql/init-contract.sql`

说明：
- 首次启动 MySQL 会自动执行
- 如果已有数据，需要手动执行 SQL

## 步骤 2：配置合约服务数据源
配置位置：`exchange-contract/src/main/resources/application.yml`

关键配置项：
- `spring.datasource.*`：连接 MySQL
- `mybatis-plus.*`：MyBatis-Plus 基础配置
- `contract.margin.min-leverage`：最小杠杆

## 步骤 3：启动合约服务
```bash
mvn -f pom.xml -pl exchange-contract -am spring-boot:run -DskipTests
```

## 步骤 4：接口说明

### 术语提示（与接口字段一致）
- `action`：OPEN=开仓，CLOSE=平仓
- `side`：LONG=看涨做多，SHORT=看跌做空
- `type`：LIMIT=限价挂单，MARKET=市价成交
- `marginMode`：CROSS=全仓，ISOLATED=逐仓
- `price`：市价单为保护价，用于限制极端滑点
- `quantity`：合约数量
更多术语解释见 `doc/合约术语速查表.md`。

### 4.1 充值保证金账户
- 地址：`POST /api/contract/account/deposit`
- 示例：
```bash
curl -X POST http://localhost:18084/api/contract/account/deposit \
  -H 'Content-Type: application/json' \
  -d '{"userId":1,"amount":1000}'
```
请求 JSON：
```json
{
  "userId": 1,
  "amount": 1000
}
```
响应 JSON：
```json
{
  "code": 0,
  "message": "操作成功",
  "data": {
    "userId": 1,
    "balance": 1000
  },
  "timestamp": 1730000000000
}
```

## 合约模型说明（版）
- **保证金账户**：用于记录可用保证金余额（模拟）
- **持仓**：按用户 + 交易对 + 方向 + 保证金模式唯一
- **开仓**：扣减保证金，更新持仓均价与数量
- **平仓**：释放保证金并结算盈亏

## 强平价计算（版）
- 多仓：`强平价 = 开仓均价 * (1 - 1/杠杆)`
- 空仓：`强平价 = 开仓均价 * (1 + 1/杠杆)`

## 提示
- 当前版本为“撮合前置”的简化合约模型
- 生产环境需要接入撮合引擎、风险度、强平队列等
