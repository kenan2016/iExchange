# 阶段 4：现货撮合引擎

## 目标
- 支持多交易对下单
- 支持限价单/市价单撮合
- 支持撤单与订单查询
- 成交落库并推送 Kafka 成交事件

## 前置条件
- 已完成阶段 3（钱包与流水）
- MySQL 与 Kafka 正常启动

## 步骤 1：初始化现货表
SQL 文件：`infra/mysql/init-spot.sql`

说明：
- 如果 MySQL 容器首次启动，会自动执行初始化脚本
- 如果容器已存在，请手动执行 SQL

## 步骤 2：配置撮合服务数据源
配置位置：`exchange-spot/src/main/resources/application.yml`

关键配置项：
- `spring.datasource.*`：连接 MySQL
- `mybatis-plus.*`：MyBatis-Plus 基础配置
- `spot.trade.topic`：成交事件主题

## 步骤 3：启动撮合服务
```bash
mvn -f pom.xml -pl exchange-spot -am spring-boot:run -DskipTests
```

## 步骤 4：接口说明

### 4.1 下限价买单
- 地址：`POST /api/spot/order`
- 请求示例：
```bash
curl -X POST http://localhost:18083/api/spot/order \
  -H 'Content-Type: application/json' \
  -d '{"userId":1,"symbol":"BTC_USDT","side":"BUY","type":"LIMIT","price":30000,"quantity":0.01}'
```

### 4.2 下限价卖单
- 地址：`POST /api/spot/order`
- 请求示例：
```bash
curl -X POST http://localhost:18083/api/spot/order \
  -H 'Content-Type: application/json' \
  -d '{"userId":2,"symbol":"BTC_USDT","side":"SELL","type":"LIMIT","price":30000,"quantity":0.01}'
```

### 4.3 下市价单
- 地址：`POST /api/spot/order`
- 请求示例：
```bash
  curl -X POST http://localhost:18083/api/spot/order \
    -H 'Content-Type: application/json' \
    -d '{"userId":3,"symbol":"BTC_USDT","side":"BUY","type":"MARKET","price":30000,"quantity":0.02}'
```

### 4.4 撤单
- 地址：`POST /api/spot/order/cancel`
- 请求示例：
```bash
curl -X POST http://localhost:18083/api/spot/order/cancel \
  -H 'Content-Type: application/json' \
      -d '{"userId":1,"orderId":1001}'
```

### 4.5 查询订单
- 地址：`GET /api/spot/order`
- 请求示例：
```bash
curl "http://localhost:18083/api/spot/order?orderId=1001"
```

## 撮合规则说明（版）
- 价格优先：买单按价格从高到低，卖单按价格从低到高
- 时间优先：同价位按照进入订单簿的先后顺序（FIFO）
- 市价单只吃现有订单，不会进入订单簿

## 提示
- 订单簿在内存中，服务重启后会清空
- 生产环境需要考虑订单簿持久化与恢复

## 订单状态说明
- `NEW`：未成交（限价单挂单）
- `PARTIAL_FILLED`：部分成交
- `FILLED`：全部成交
- `CANCELED`：撤单或市价单未成交部分直接取消

## 成交事件（Kafka）
- 成交后会向 `spot.trade` 主题发送事件
- 事件字段：symbol、buyOrderId、sellOrderId、price、quantity、takerSide、tradeTime
