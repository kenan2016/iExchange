# 阶段 7：资金费率

## 目标
- 计算资金费率
- 结算资金费率并划转到保证金账户
- 记录费率与结算明细

## 前置条件
- 已完成阶段 6（永续合约核心）
- MySQL 正常启动

## 步骤 1：初始化资金费率表
SQL 文件：`infra/mysql/init-contract.sql`

说明：
- 新增 `contract_funding_rate` 与 `contract_funding_settlement`
- 如果已有数据，请手动执行 SQL

## 步骤 2：配置资金费率参数
配置位置：`exchange-contract/src/main/resources/application.yml`

关键配置：
- `contract.funding.default-rate`：默认费率
- `contract.funding.max-rate`：费率上限
- `contract.funding.rate-coefficient`：费率系数
- `contract.funding.interval-seconds`：结算间隔（秒）

## 步骤 3：启动合约服务
```bash
mvn -f pom.xml -pl exchange-contract -am spring-boot:run -DskipTests
```

## 步骤 4：接口说明

### 术语提示（与接口字段一致）
- `markPrice`：标记价，用于强平与资金费率参考
- `indexPrice`：指数价，现货参考价格
- `rate`：资金费率，正数=多头支付，负数=多头收取
- `nextSettleTime`：下次结算时间（Unix 秒）

### 4.1 计算资金费率
- 地址：`POST /api/contract/funding/rate/calc`
- 示例：
```bash
curl -X POST http://localhost:18084/api/contract/funding/rate/calc \
  -H 'Content-Type: application/json' \
  -d '{"symbol":"BTCUSDT-PERP","markPrice":30000,"indexPrice":29950}'
```
请求 JSON：
```json
{
  "symbol": "BTCUSDT-PERP",
  "markPrice": 30000,
  "indexPrice": 29950
}
```
响应 JSON：
```json
{
  "code": 0,
  "message": "计算成功",
  "data": {
    "symbol": "BTCUSDT-PERP",
    "rate": 0.0001,
    "nextSettleTime": 1730002880
  },
  "timestamp": 1730000000000
}
```

### 4.2 查询最新资金费率
- 地址：`GET /api/contract/funding/rate`
- 示例：
```bash
curl "http://localhost:18084/api/contract/funding/rate?symbol=BTCUSDT-PERP"
```
响应 JSON：
```json
{
  "code": 0,
  "message": "查询成功",
  "data": {
    "symbol": "BTCUSDT-PERP",
    "rate": 0.0001,
    "nextSettleTime": 1730002880
  },
  "timestamp": 1730000000000
}
```

### 4.3 结算资金费率
- 地址：`POST /api/contract/funding/settle`
- 示例：
```bash
curl -X POST http://localhost:18084/api/contract/funding/settle \
  -H 'Content-Type: application/json' \
  -d '{"symbol":"BTCUSDT-PERP","markPrice":30000,"indexPrice":29950}'
```
请求 JSON：
```json
{
  "symbol": "BTCUSDT-PERP",
  "markPrice": 30000,
  "indexPrice": 29950
}
```
响应 JSON：
```json
{
  "code": 0,
  "message": "结算完成",
  "data": {
    "symbol": "BTCUSDT-PERP",
    "rate": 0.0001,
    "positionCount": 10,
    "totalAmount": 12.5
  },
  "timestamp": 1730000000000
}
```

## 结算逻辑说明（版）
- 资金费率公式（简化）：  
  `rate = (markPrice - indexPrice) / indexPrice * rateCoefficient`
- 若费率超出上限，按上限截断
- 费率为正时：多仓付费、空仓收取
- 费率为负时：空仓付费、多仓收取
