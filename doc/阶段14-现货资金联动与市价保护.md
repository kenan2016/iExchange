# 阶段 14：现货资金联动与市价保护

## 目标
- 现货下单与钱包资金冻结/解冻/成交结算联动
- 市价单增加保护价格，避免吃穿盘口

## 涉及模块
- `exchange-api`
- `exchange-wallet`
- `exchange-spot`

## 步骤 1：新增钱包 Dubbo 接口
新增文件：
- `exchange-api/src/main/java/com/iexchange/api/wallet/WalletAccountDTO.java`
- `exchange-api/src/main/java/com/iexchange/api/wallet/WalletAccountService.java`

说明：
- 用于现货服务调用钱包服务完成冻结、解冻与成交入账。

## 步骤 2：钱包服务支持交易入账
改动文件：
- `exchange-wallet/src/main/java/com/iexchange/wallet/service/WalletService.java`
- `exchange-wallet/src/main/java/com/iexchange/wallet/service/impl/WalletServiceImpl.java`
- `exchange-wallet/src/main/java/com/iexchange/wallet/service/WalletFlowType.java`

说明：
- 新增 `TRADE_IN` 流水类型。
- 新增 `tradeIn` 方法，用于成交后将资产入账。

## 步骤 3：钱包 Dubbo 服务提供方
新增文件：
- `exchange-wallet/src/main/java/com/iexchange/wallet/service/WalletAccountDubboService.java`

说明：
- 将钱包操作封装为 Dubbo 服务，供现货模块调用。

## 步骤 4：现货下单冻结资金
改动文件：
- `exchange-spot/src/main/java/com/iexchange/spot/service/impl/SpotOrderServiceImpl.java`

关键点：
- 买单冻结 `quote` 资产，冻结额包含手续费。
- 卖单冻结 `base` 资产。
- 冻结失败则订单标记为取消。

## 步骤 5：成交结算联动钱包
改动文件：
- `exchange-spot/src/main/java/com/iexchange/spot/engine/SpotMatchingEngine.java`

关键点：
- 买方：扣减冻结金额，解冻价差，入账基础资产。
- 卖方：扣减冻结数量，入账计价资产（扣除手续费）。

## 步骤 6：市价单保护价格
改动文件：
- `exchange-spot/src/main/java/com/iexchange/spot/service/impl/SpotOrderServiceImpl.java`
- `exchange-spot/src/main/java/com/iexchange/spot/engine/SpotMatchingEngine.java`
- `exchange-spot/src/main/java/com/iexchange/spot/schedule/SpotPlanOrderTriggerScheduler.java`

说明：
- 市价单必须传入 `price` 作为保护价。
- 撮合时保护价与限价单同等约束价格区间。
- 计划委托的市价单使用触发价作为保护价。

## 验证方式
1. 先向钱包入金：
```bash
curl -X POST http://127.0.0.1:18082/api/wallet/deposit \
  -H "Content-Type: application/json" \
  -d '{"userId":1,"asset":"USDT","amount":10000,"requestId":"req-usdt-1"}'
```

2. 下市价单（必须携带保护价）：
```bash
curl -X POST http://127.0.0.1:18083/api/spot/order \
  -H "Content-Type: application/json" \
  -d '{"userId":1,"symbol":"BTC_USDT","side":"BUY","type":"MARKET","price":30000,"quantity":0.01}'
```

3. 查看钱包余额与流水变化。

## 小结
- 现货撮合与钱包资金实现了联动。
- 市价单增加保护价，避免极端滑点。
