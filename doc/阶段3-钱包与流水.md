# 阶段 3：钱包与流水

## 目标
- 建立钱包账户与流水表
- 支持入金、出金、冻结、解冻
- 实现幂等请求（避免重复扣款/入账）

## 前置条件
- 已完成阶段 2（用户与登录）
- MySQL 正常启动

## 步骤 1：初始化钱包表
SQL 文件：`infra/mysql/init-wallet.sql`

说明：
- 如果 MySQL 容器是第一次启动，会自动执行初始化脚本
- 如果容器已存在并持久化数据，需要手动执行该 SQL

## 步骤 2：配置钱包服务数据源
配置位置：`exchange-wallet/src/main/resources/application.yml`

关键配置项：
- `spring.datasource.*`：连接 MySQL
- `mybatis-plus.*`：MyBatis-Plus 基础配置

## 步骤 3：启动钱包服务
```bash
mvn -f pom.xml -pl exchange-wallet -am spring-boot:run -DskipTests
```

## 步骤 4：接口说明
### 入金接口
- 地址：`POST /api/wallet/deposit`
- 请求示例：
```bash
curl -X POST http://localhost:18082/api/wallet/deposit \
  -H 'Content-Type: application/json' \
  -d '{"userId":1,"asset":"USDT","amount":100,"requestId":"req-1001"}'
```

### 出金接口
- 地址：`POST /api/wallet/withdraw`
- 请求示例：
```bash
curl -X POST http://localhost:18082/api/wallet/withdraw \
  -H 'Content-Type: application/json' \
  -d '{"userId":1,"asset":"USDT","amount":10,"requestId":"req-1002"}'
```

### 冻结接口
- 地址：`POST /api/wallet/freeze`
- 请求示例：
```bash
curl -X POST http://localhost:18082/api/wallet/freeze \
  -H 'Content-Type: application/json' \
  -d '{"userId":1,"asset":"USDT","amount":5,"requestId":"req-1003"}'
```

### 解冻接口
- 地址：`POST /api/wallet/unfreeze`
- 请求示例：
```bash
curl -X POST http://localhost:18082/api/wallet/unfreeze \
  -H 'Content-Type: application/json' \
  -d '{"userId":1,"asset":"USDT","amount":5,"requestId":"req-1004"}'
```

### 查询余额
- 地址：`GET /api/wallet/balance`
- 请求示例：
```bash
curl "http://localhost:18082/api/wallet/balance?userId=1&asset=USDT"
```

## 幂等设计说明
- 每次操作需要传入 `requestId`
- `wallet_flow` 表通过唯一索引 `(user_id, asset, flow_type, business_id)` 保证幂等
- 并发写入场景使用分布式锁串行化同一资产账户（见阶段 3.1）
- SETNX 幂等演示放在行情模块（见阶段 3.2）

- 文档（本文件）
