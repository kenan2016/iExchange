# 阶段 5：行情与 K 线

## 目标
- 消费撮合成交事件
- 生成 Ticker 与 1 分钟 K 线
- 支持 WebSocket 行情推送
- K 线落库到 MongoDB

## 前置条件
- 已完成阶段 4（现货撮合引擎）
- Kafka 与 MongoDB 正常启动

## 步骤 1：配置行情服务
配置文件：`exchange-market/src/main/resources/application.yml`

关键配置：
- `spring.data.mongodb.uri`：MongoDB 地址
- `market.trade.topic`：成交主题（默认 `spot.trade`）
- `market.websocket.port`：WebSocket 端口（默认 19090）

## 步骤 2：启动行情服务
```bash
mvn -f pom.xml -pl exchange-market -am spring-boot:run -DskipTests
```

## 步骤 3：接口说明

### 3.1 查询 Ticker
- 地址：`GET /api/market/ticker`
- 示例：
```bash
curl "http://localhost:18085/api/market/ticker?symbol=BTC_USDT"
```

### 3.2 查询 K 线
- 地址：`GET /api/market/klines`
- 示例：
```bash
curl "http://localhost:18085/api/market/klines?symbol=BTC_USDT&interval=1m&limit=50"
```

支持周期示例（5m）：
```bash
curl "http://localhost:18085/api/market/klines?symbol=BTC_USDT&interval=5m&limit=50"
```

合成周期示例（30m）：
```bash
curl "http://localhost:18085/api/market/klines?symbol=BTC_USDT&interval=30m&limit=50"
```

## 步骤 4：WebSocket 推送
连接地址：
- 订阅指定交易对：`ws://localhost:19090/ws?symbol=BTC_USDT`
- 全量订阅：`ws://localhost:19090/ws`

消息格式（示例）：
```json
{
  "type": "trade",
  "time": "2026-01-19T21:00:00",
  "data": {
    "symbol": "BTC_USDT",
    "price": 30000,
    "quantity": 0.01,
    "takerSide": "BUY"
  }
}
```

## K 线聚合说明（版）
- 支持 1m/5m/15m/30m/1h 周期
- 示例：使用 6 根 5m 合成 30m（实现见 `KlineServiceImpl`）
- 成交进入对应分钟桶，更新 open/high/low/close/volume
- 结果写入 MongoDB（集合：`kline`，通过 interval 区分）
- 合成模式：`market.kline.aggregate-mode` 可选 `mongo` / `redis-first`

## KlineBucket 参数计算公式
对应对象：`com.iexchange.market.service.model.KlineBucket`

设：
- `t` = 成交时间（秒级时间戳）
- `p_i` = 第 i 笔成交价
- `q_i` = 第 i 笔成交量
- `S` = 当前周期秒数（1m=60，5m=300，15m=900，1h=3600）

时间边界：
- `startTime = t - (t % S)`
- `endTime = startTime + S`

当某个桶内第一笔成交到来（初始化）：
- `open = p_1`
- `high = p_1`
- `low = p_1`
- `close = p_1`
- `volume = q_1`

当后续第 i 笔成交到来（i >= 2）：
- `high = max(high, p_i)`
- `low = min(low, p_i)`
- `close = p_i`
- `volume = volume + q_i`
- `open` 保持为第一笔成交价，不再变化

按数学形式表示（桶内共 n 笔）：
- `open = p_1`
- `high = max(p_1, p_2, ..., p_n)`
- `low = min(p_1, p_2, ..., p_n)`
- `close = p_n`
- `volume = Σ(q_i), i=1..n`

## Redis 缓存说明
- 最新 N 条 K 线会写入 Redis（默认 500 条）
- 查询接口优先读 Redis，未命中再读 MongoDB
- 配置项：`market.kline.cache-size`（见 `exchange-market/src/main/resources/application.yml`）
- Ticker 与 Depth 也写入 Redis，便于高频读取

## 深度接口说明
- 地址：`GET /api/market/depth`
- 示例：
```bash
curl "http://localhost:18085/api/market/depth?symbol=BTC_USDT&limit=20"
```

深度生成说明：
- 版深度基于成交事件累加得到，非真实订单簿
- 真实交易所需由撮合订单簿驱动
- 配置项：`market.depth.levels` 控制深度档位数
