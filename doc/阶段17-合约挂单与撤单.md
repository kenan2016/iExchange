# 阶段 17：合约挂单与撤单

## 目标
- 限价单支持挂单与定时撮合
- 提供合约撤单接口

## 涉及模块
- `exchange-contract`

## 步骤 1：限价单挂单逻辑
改动文件：
- `exchange-contract/src/main/java/com/iexchange/contract/service/impl/ContractOrderServiceImpl.java`

说明：
- 限价单若价格未满足成交条件，则写入订单表并保持 `NEW` 状态。
- 成交条件参考最新标记价。

## 步骤 2：挂单撮合任务
新增文件：
- `exchange-contract/src/main/java/com/iexchange/contract/schedule/ContractOrderMatchScheduler.java`

说明：
- 定时拉取 `NEW` 状态的限价单。
- 满足条件则成交并更新仓位。

## 步骤 3：撤单接口
新增文件：
- `exchange-contract/src/main/java/com/iexchange/contract/dto/ContractOrderCancelRequest.java`
- `exchange-contract/src/main/java/com/iexchange/contract/controller/ContractController.java`

说明：
- 仅支持撤销 `NEW` 状态订单。

## 步骤 4：配置项
改动文件：
- `exchange-contract/src/main/resources/application.yml`

新增配置示例：
```yaml
contract:
  order:
    pending-enabled: true
    match-enabled: true
    match-interval-ms: 3000
```

## 验证方式
1. 提交限价单（价格偏离较大）：
```bash
curl -X POST http://127.0.0.1:18084/api/contract/order \
  -H "Content-Type: application/json" \
  -d '{"userId":1,"symbol":"BTCUSDT-PERP","action":"OPEN","side":"LONG","type":"LIMIT","price":20000,"quantity":0.01,"leverage":10,"marginMode":"ISOLATED"}'
```

2. 观察订单状态为 `NEW`。
3. 当行情触发条件时，定时任务会自动成交。
4. 如需撤单：
```bash
curl -X POST http://127.0.0.1:18084/api/contract/order/cancel \
  -H "Content-Type: application/json" \
  -d '{"userId":1,"orderId":1}'
```

## 小结
- 合约限价单支持挂单与定时撮合。
- 支持基础撤单流程，便于演示。
