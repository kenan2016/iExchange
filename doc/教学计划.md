# 交易所计划与分阶段交付清单

## 项目定位
- 面向、可运行 Demo，强调流程闭环与可读性
- 每一步完成后产出中文文档
- 所有代码与脚本必须包含中文注释

## 技术栈
- Spring Boot 3.x、JDK21、MyBatis-Plus
- MySQL8、MongoDB、Redis、Kafka、Disruptor、Netty WebSocket

## 默认参数
- 手续费：现货 0.10%，合约 0.05%（不区分 maker/taker）
- 合约杠杆：1x–20x
- 结算币种：USDT
- 交易对：现货 BTC_USDT、ETH_USDT、SOL_USDT；合约 BTCUSDT-PERP、ETHUSDT-PERP
- 登录方式：账号+密码

## 功能范围（补齐后）
- 用户与认证
  - 账号+密码登录
  - 基础会话/Token 管理
- 资产与钱包
  - 账户资产：可用/冻结/总额
  - 资金流水记录（所有资产变化必须落流水）
  - 入金/出金模拟
  - 资金变更幂等与重复请求防护
- 现货交易
  - 多交易对支持
  - 订单类型：限价单、市价单
  - 撮合规则：价格优先、时间优先（FIFO）
  - 订单生命周期：创建→撮合→部分成交/全成交→撤单→完成
  - 撤单流程与资金解冻
  - 市价单价格保护（防止吃穿盘口）
- 永续合约
  - 全仓/逐仓两种保证金模式
  - 资金费率：计算、结算、资金划转
  - 强平触发逻辑（按风险度计算，版可简化）
  - 合约仓位与保证金计算
- 行情与推送
  - 行情通道：ticker、depth、trade、kline
  - K线聚合（多周期）
  - 行情数据来源与撮合成交一致
- 费用与规则
  - 固定费率（现货/合约分别设置）
  - 手续费收取时点明确
  - 下单校验：最小下单量、价格精度、数量精度
- 非功能性（必讲）
  - 一致性边界：资金与订单的事务/补偿策略
  - 可靠性：消息重放/落库/幂等
  - 可观测性：日志、关键指标
