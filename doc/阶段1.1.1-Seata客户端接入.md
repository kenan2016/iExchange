# 阶段 1.1.1：Seata 客户端接入（Nacos 模式 + DB 存储）

## 目标
- 在各业务服务中接入 Seata 客户端
- 使用 Nacos 作为注册中心与配置中心
- 将 Seata 服务端存储模式切换为 DB

## 变更内容
- 各业务服务新增 Seata 依赖
- `application.yml` 使用 Nacos 模式配置
- 新增 Seata 服务端/客户端配置模板：
  - `infra/seata/seata-server.properties`
  - `infra/seata/seata-client.properties`
- 新增 Seata 数据库初始化脚本：`infra/mysql/init-seata.sql`

## 关键说明
- 客户端与服务端都使用 Nacos 模式，不再使用 file 模式
- Seata Server 使用 **MySQL DB 模式**持久化事务数据
- 业务侧使用 **AT 模式**（通过 `data-source-proxy-mode: AT` 显式指定）
- 事务分组映射写入 Nacos 配置
- 如果 Seata Server 运行在 Docker 中，`server-addr` 需写为 `nacos:8848`（容器内访问）

## 配置步骤（手动导入 Nacos）
1. 进入 Nacos 控制台：`http://localhost:8848/nacos`
2. 创建命名空间（Namespace ID）：`seata`
3. 创建配置（服务端）：
   - Data ID：`seata-server.properties`
   - Group：`SEATA_GROUP`
   - 配置内容：`infra/seata/seata-server.properties`
4. 创建配置（客户端）：
   - Data ID：`seata-client.properties`
   - Group：`SEATA_GROUP`
   - 配置内容：`infra/seata/seata-client.properties`

## 数据库初始化说明
- 使用 Docker 初始化脚本：`infra/mysql/init-seata.sql`
- 如果 MySQL 容器已存在且已持久化数据，脚本不会自动执行，请手动导入。

## 客户端配置示例（节选）
```yaml
seata:
  enabled: true # 启用 Seata
  data-source-proxy-mode: AT # 显式使用 AT 模式
  application-id: exchange-user # Seata 应用标识
  tx-service-group: exchange_tx_group # 全局事务分组名
  registry:
    type: nacos # 使用 Nacos 注册中心
    nacos:
      server-addr: 127.0.0.1:8848 # Nacos 地址
      group: SEATA_GROUP # Nacos 分组
      application: seata-server # Seata Server 服务名
      cluster: default # 集群名
  config:
    type: nacos # 使用 Nacos 配置中心
    nacos:
      server-addr: 127.0.0.1:8848 # Nacos 地址
      group: SEATA_GROUP # 配置分组
      data-id: seata-client.properties # 客户端配置 DataId
```
