# 阶段 16：合约资金费率定时与全仓/逐仓差异

## 目标
- 资金费率支持定时计算与自动结算（可控）
- 全仓/逐仓在强平价计算上体现差异

## 涉及模块
- `exchange-contract`
- `exchange-market`

## 步骤 1：定时任务与行情价格获取
新增文件：
- `exchange-contract/src/main/java/com/iexchange/contract/client/MarketPriceClient.java`
- `exchange-contract/src/main/java/com/iexchange/contract/dto/MarketTickerResult.java`
- `exchange-contract/src/main/java/com/iexchange/contract/schedule/ContractFundingScheduler.java`

说明：
- 通过行情服务获取最新价格作为标记价。
- 定时任务周期可在配置中调整。

## 步骤 2：合约交易对查询补充
改动文件：
- `exchange-contract/src/main/java/com/iexchange/contract/service/ContractSymbolService.java`
- `exchange-contract/src/main/java/com/iexchange/contract/service/impl/ContractSymbolServiceImpl.java`

说明：
- 新增 `listEnabled` 便于定时任务遍历交易对。

## 步骤 3：全仓/逐仓差异化
改动文件：
- `exchange-contract/src/main/java/com/iexchange/contract/service/impl/ContractOrderServiceImpl.java`

说明：
- 逐仓按当前杠杆计算强平价。
- 全仓引入账户余额作为缓冲，强平价更远。

## 步骤 4：开启定时任务
改动文件：
- `exchange-contract/src/main/java/com/iexchange/contract/ContractApplication.java`
- `exchange-contract/src/main/resources/application.yml`

新增配置示例：
```yaml
contract:
  funding:
    auto-enabled: true
    auto-settle: false
    auto-interval-ms: 60000
    settle-window-seconds: 5
  market:
    service-url: http://127.0.0.1:18085
```

## 验证方式
1. 启动 `exchange-market` 与 `exchange-contract`。
2. 设置 `auto-enabled=true` 后观察日志，确认定时任务触发。
3. 通过接口查询资金费率：
```bash
curl -X GET "http://127.0.0.1:18084/api/contract/funding/rate?symbol=BTCUSDT-PERP"
```

## 小结
- 资金费率可定时计算，结算开关由配置控制。
- 全仓/逐仓差异在强平价计算上体现。
