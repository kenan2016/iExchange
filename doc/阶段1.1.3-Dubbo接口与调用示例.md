# 阶段 1.1.3：Dubbo 接口与调用示例

## 目标
- 拆分公共 API 模块（供服务间共享）
- 提供一个 Dubbo Provider 与 Consumer 示例
- 打通基础 RPC 调用链路

## 变更内容
- 新增模块 `exchange-api`
- 用户服务提供 Dubbo 接口实现
- 钱包服务提供 Dubbo 调用示例接口
- 增加 Dubbo Nacos 注册与元数据上报配置

## 结构说明
- `exchange-api`：存放 Dubbo 接口与 DTO
- `exchange-user`：作为 Provider 暴露用户查询服务
- `exchange-wallet`：作为 Consumer 调用用户查询服务

## 示例接口
```java
public interface UserQueryService {
    UserDTO getById(Long userId);
}
```

## 示例调用
```java
@DubboReference
private UserQueryService userQueryService;
```

## Dubbo 元数据配置要点
- 为避免只发现 Spring Cloud 实例，需上报 Dubbo 元数据：
```yaml
dubbo:
  application:
    name: exchange-user-dubbo # Dubbo 应用名（与 Spring 服务名区分）
    metadata-type: remote # 元数据使用远程模式
  registry:
    address: nacos://127.0.0.1:8848?group=DUBBO_GROUP&namespace=dubbo # Dubbo 注册中心
  metadata-report:
    address: nacos://127.0.0.1:8848?group=DUBBO_GROUP&namespace=dubbo # 元数据上报到 Nacos
```

## 测试说明（手动验证）
1. 启动基础依赖与全部服务
2. 访问钱包服务接口：
   - `GET http://localhost:18082/wallet/user/1`
3. 返回示例数据：`{"userId":1,"username":"user_1"}`
