# 阶段 13：系统整合演示与操作手册

## 目标
- 端到端跑通用户、钱包、现货撮合、行情、合约核心流程
- 给学生一套可复现的操作步骤与示例命令

## 一、环境准备
### 1. 中间件准备
请先完成 `doc/中间件Docker安装指南.md` 中的容器部署：
- MySQL 8
- Redis
- MongoDB
- Kafka
- Nacos
- Sentinel
- Seata（可选）

### 2. 数据库初始化
MySQL 账号：`root` / `root`

1) 创建业务库：
```bash
mysql -uroot -proot -e "CREATE DATABASE IF NOT EXISTS iexchange DEFAULT CHARSET utf8mb4;"
```

2) 初始化业务表：
```bash
mysql -uroot -proot iexchange < infra/mysql/init-user.sql
mysql -uroot -proot iexchange < infra/mysql/init-wallet.sql
mysql -uroot -proot iexchange < infra/mysql/init-spot.sql
mysql -uroot -proot iexchange < infra/mysql/init-contract.sql
```

3) 如果 Seata 使用 DB 模式（可选）：
```bash
mysql -uroot -proot -e "CREATE DATABASE IF NOT EXISTS seata DEFAULT CHARSET utf8mb4;"
mysql -uroot -proot seata < infra/mysql/init-seata.sql
```

## 二、服务启动顺序
建议按以下顺序启动（端口见配置）：
1. Nacos
2. Seata（可选）
3. Kafka
4. `exchange-user`（18081）
5. `exchange-wallet`（18082）
6. `exchange-spot`（18083）
7. `exchange-contract`（18084）
8. `exchange-market`（18085，WebSocket 19090）
9. `exchange-gateway`（18080，可选）

## 三、端到端演示流程
> 注意：`exchange-user` 启动后会自动创建演示用户：`demo / demo123`。

### 1) 登录获取 Token
```bash
curl -X POST http://127.0.0.1:18081/api/auth/login \
  -H "Content-Type: application/json" \
  -d '{"username":"demo","password":"demo123"}'
```

### 2) 查询登录用户信息（可选）
```bash
curl -X GET http://127.0.0.1:18081/api/auth/me \
  -H "X-Token: <替换为上一步的token>"
```

### 3) 钱包入金（模拟）
```bash
curl -X POST http://127.0.0.1:18082/api/wallet/deposit \
  -H "Content-Type: application/json" \
  -d '{"userId":1,"asset":"USDT","amount":10000,"requestId":"req-usdt-1"}'

curl -X POST http://127.0.0.1:18082/api/wallet/deposit \
  -H "Content-Type: application/json" \
  -d '{"userId":1,"asset":"BTC","amount":1,"requestId":"req-btc-1"}'
```

### 4) 现货下单并撮合
> 交易对使用初始化数据：`BTC_USDT`。
> 市价单需传入保护价格 `price`。

买单：
```bash
curl -X POST http://127.0.0.1:18083/api/spot/order \
  -H "Content-Type: application/json" \
  -d '{"userId":1,"symbol":"BTC_USDT","side":"BUY","type":"LIMIT","price":30000,"quantity":0.01}'
```

卖单（与买单价格交叉）：
```bash
curl -X POST http://127.0.0.1:18083/api/spot/order \
  -H "Content-Type: application/json" \
  -d '{"userId":1,"symbol":"BTC_USDT","side":"SELL","type":"LIMIT","price":30000,"quantity":0.01}'
```

### 5) 行情查询（验证 Disruptor + Kafka 链路）
```bash
curl -X GET "http://127.0.0.1:18085/api/market/ticker?symbol=BTC_USDT"

curl -X GET "http://127.0.0.1:18085/api/market/klines?symbol=BTC_USDT&interval=1m&limit=10"

curl -X GET "http://127.0.0.1:18085/api/market/depth?symbol=BTC_USDT&limit=5"
```

### 6) 合约保证金入金
```bash
curl -X POST http://127.0.0.1:18084/api/contract/account/deposit \
  -H "Content-Type: application/json" \
  -d '{"userId":1,"amount":1000}'
```

### 7) 合约开仓（逐仓示例）
```bash
curl -X POST http://127.0.0.1:18084/api/contract/order \
  -H "Content-Type: application/json" \
  -d '{"userId":1,"symbol":"BTCUSDT-PERP","action":"OPEN","side":"LONG","type":"LIMIT","price":30000,"quantity":0.01,"leverage":10,"marginMode":"ISOLATED"}'
```

## 四、常见排查点
- **Nacos 中无服务实例**：检查各服务 `spring.application.name` 与 `server-addr` 是否一致。
- **Seata 报 `vgroupMapping` 缺失**：确认 Nacos 中配置项已创建。
- **行情无数据**：确认 `exchange-spot` 已产生成交，Kafka topic 正常。
- **Mongo 无数据**：确认 `exchange-market` 启动正常并连接到 Mongo。

## 五、建议
- 先跑通现货与行情，再演示合约与资金费率。
- 将每一步的请求与响应保存成课堂记录，便于学生复现。
