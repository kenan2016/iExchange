# 阶段23-统一返回包装（R）

## 目标
- 统一所有 Controller 的返回结构
- 方便前端与演示统一处理

## R 结构设计
- `code`：状态码，成功为 0，失败为 500
- `message`：提示信息
- `data`：具体业务数据
- `timestamp`：响应时间戳（毫秒）
说明：`data` 中仅包含业务字段，不再重复 `success` / `message`。

## 示例
成功：
```json
{
  "code": 0,
  "message": "操作成功",
  "data": {
    "orderId": 10001
  },
  "timestamp": 1730000000000
}
```

失败：
```json
{
  "code": 500,
  "message": "参数错误",
  "data": null,
  "timestamp": 1730000000000
}
```

## 核心实现
- 统一返回类：`com.iexchange.common.response.R`
- Controller 使用 `R.ok(...)`、`R.fail(...)` 包装

## 提示
- 现有业务响应对象仍保留（data 中承载原响应内容）
- 如需进一步简化，可将业务响应对象改为纯数据结构
