# 阶段24-日志框架接入

## 目标
- 统一日志输出格式
- 支持控制台与文件滚动日志

## 实现方式
- 使用 Spring Boot 默认日志框架 Logback
- 在 `exchange-common` 提供全局 `logback-spring.xml`

## 配置说明
日志配置文件：`exchange-common/src/main/resources/logback-spring.xml`
- 控制台输出：`CONSOLE`
- 文件输出：`FILE`
- 日志路径：`${LOG_PATH:-logs}`
- 文件命名：`${APP_NAME}.log`（APP_NAME 来自 `spring.application.name`）
- 滚动策略：按天 + 按大小（50MB），保留 14 天

## 示例
启动任一服务后，可在 `logs/` 目录看到日志文件：
- `exchange-user.log`
- `exchange-spot.log`

## 提示
- 需要更多业务日志时，请使用 `LoggerFactory.getLogger(...)`
- 生产环境可通过 `LOG_PATH` 环境变量调整日志目录
