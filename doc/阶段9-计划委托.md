# 阶段 9：计划委托（版）

## 目标
- 支持计划委托下单与撤单
- 按触发价生成真实现货订单
- 定时轮询行情完成触发

## 前置条件
- 已完成阶段 4（现货撮合引擎）
- 已完成阶段 5（行情服务）
- MySQL 与行情服务可用

## 步骤 1：创建表结构
执行脚本：`infra/mysql/init-spot.sql`

关键表：`spot_plan_order`
- `trigger_price`：触发价
- `order_price`：触发后委托价（市价单可为 0）
- `status`：NEW/TRIGGERED/CANCELED

## 步骤 2：配置计划委托参数
配置文件：`exchange-spot/src/main/resources/application.yml`

关键配置：
- `spot.plan.enabled`：是否启用触发任务
- `spot.plan.check-interval-ms`：触发轮询间隔
- `spot.plan.market-service-url`：行情服务地址

## 步骤 3：接口说明

### 3.1 创建计划委托
- 地址：`POST /api/spot/plan`
- 示例：
```bash
curl -X POST "http://localhost:18083/api/spot/plan" \
  -H "Content-Type: application/json" \
  -d '{"userId":1,"symbol":"BTC_USDT","side":"BUY","type":"LIMIT","triggerPrice":30000,"orderPrice":29950,"quantity":0.01}'
```

### 3.2 撤销计划委托
- 地址：`POST /api/spot/plan/cancel`
- 示例：
```bash
curl -X POST "http://localhost:18083/api/spot/plan/cancel" \
  -H "Content-Type: application/json" \
  -d '{"userId":1,"planOrderId":1}'
```

### 3.3 查询计划委托列表
- 地址：`GET /api/spot/plan?userId=1`
- 示例：
```bash
curl "http://localhost:18083/api/spot/plan?userId=1"
```

## 步骤 4：触发规则说明
- BUY 计划单：最新价 >= 触发价时触发
- SELL 计划单：最新价 <= 触发价时触发
- 触发后生成真实现货订单，并将计划单状态改为 TRIGGERED

## 说明
- 该方案使用行情服务提供的 Ticker 价格作为触发依据
- 触发任务通过定时轮询实现，适合演示
