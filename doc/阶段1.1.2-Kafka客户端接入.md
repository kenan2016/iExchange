# 阶段 1.1.2：Kafka 客户端接入

## 目标
- 在关键服务中接入 Kafka 客户端
- 配置基础生产者/消费者参数
- 为撮合与行情解耦打基础

## 变更内容
- 现货服务、行情服务新增 `spring-kafka` 依赖
- `application.yml` 增加 Kafka 连接与消费者配置

## 关键说明
- 目前只做基础连接配置，不创建 Topic
- 后续在撮合模块会由撮合结果推送消息到行情模块

## 骨架配置示例（节选）
```yaml
spring:
  kafka:
    bootstrap-servers: 127.0.0.1:9092 # Kafka 地址
    producer:
      key-serializer: org.apache.kafka.common.serialization.StringSerializer # key 序列化
      value-serializer: org.apache.kafka.common.serialization.StringSerializer # value 序列化
    consumer:
      group-id: exchange-spot # 消费组
      auto-offset-reset: earliest # 从最早位置开始消费
      key-deserializer: org.apache.kafka.common.serialization.StringDeserializer # key 反序列化
      value-deserializer: org.apache.kafka.common.serialization.StringDeserializer # value 反序列化
    listener:
      missing-topics-fatal: false # 主题不存在时不阻断启动
```
