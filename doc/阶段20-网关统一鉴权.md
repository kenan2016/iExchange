# 阶段20-网关统一鉴权

## 目标
- 在网关统一校验 Token
- 将用户身份传递给下游服务

## 设计说明
- Token 由用户服务签发 JWT（包含 userId、username、过期时间）
- 网关收到请求后校验 `X-Token` 的签名与过期时间
- 校验通过后注入 `X-User-Id`、`X-Username` 头部，便于下游复用
- 支持白名单路径，放行登录与行情等公开接口

## 配置项
```yaml
gateway:
  auth:
    enabled: true # 是否开启网关鉴权
    ignore-paths:
      - /api/auth/login
      - /api/market/**

jwt:
  secret: iexchange-demo-secret-please-change-32bytes # JWT 密钥
  issuer: iexchange # 发行者标识
```

## 核心实现
- 统一鉴权过滤器：`AuthGlobalFilter`
- JWT 校验服务：`JwtTokenService`
- 读取 `X-Token`，校验 JWT 并解析用户 ID
- 未通过则返回 401 JSON

## 验证步骤
1. 访问 `/api/auth/login` 获取 Token
2. 访问业务接口时带上 `X-Token` 头
3. 未携带 Token 或 Token 无效将返回 401

## 提示
- JWT 是无状态方案，服务端无需保存 Token
- 如需强制失效，可引入黑名单或刷新 Token 方案
