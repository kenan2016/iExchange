# 阶段 1.1.4：Sentinel 限流演示

## 目标
- 打通 Sentinel 与 Gateway 的限流适配
- 提供一个“网关路由限流”示例规则

## 变更内容
- Gateway 增加 Sentinel 网关适配依赖
- Gateway 增加限流规则初始化配置类

## 核心配置说明
- 规则针对路由 `exchange-user`
- 限流规则：QPS=5，每秒最多 5 次请求

## 规则示例
```java
// 对路由 "exchange-user" 设置 QPS 限流（每秒 5 个请求）
rules.add(new GatewayFlowRule("exchange-user").setCount(5).setIntervalSec(1));
```

## 手动验证方式
1. 启动所有服务与网关
2. 连续快速访问网关路由（示例）：
   - `GET http://localhost:18080/exchange-user/xxx`
3. 超过阈值后会触发限流（返回 429 或默认限流提示）
