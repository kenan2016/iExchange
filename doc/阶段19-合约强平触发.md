# 阶段19-合约强平触发

## 目标
- 当行情触发强平价时，自动生成市价平仓订单
- 形成合约风险控制的闭环

## 触发规则（简化）
- LONG 持仓：`markPrice <= liquidationPrice` 时触发
- SHORT 持仓：`markPrice >= liquidationPrice` 时触发
- 触发后生成 `MARKET + CLOSE` 订单，数量为持仓数量

## 配置项
```yaml
contract:
  liquidation:
    enabled: true # 是否开启强平触发任务
    check-interval-ms: 5000 # 检查周期（毫秒）
```

## 处理流程
1. 定时任务读取持仓列表
2. 按交易对获取最新标记价格
3. 触发强平条件则生成市价平仓订单
4. 平仓成交后释放保证金、更新仓位与手续费流水

## 提示
- 强平属于风险控制流程，不与用户下单混淆
- 实盘会有更复杂的风险梯度与撮合队列，这里用定时扫描演示
