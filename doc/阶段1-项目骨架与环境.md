# 阶段 1：项目骨架与环境

## 目标
- 建立多模块工程骨架
- 准备基础依赖环境（MySQL、MongoDB、Redis、Kafka）
- 提供一键启动脚本，便于演示

## 前置条件
- JDK 21
- Maven 3.9+
- Docker Desktop（用于启动基础依赖）

## 目录结构（骨架）
```
./
├── exchange-common            # 公共模块
├── exchange-user              # 用户服务
├── exchange-wallet            # 钱包服务
├── exchange-spot              # 现货撮合服务
├── exchange-contract          # 永续合约服务
├── exchange-market            # 行情服务
├── exchange-gateway           # API 网关/入口
├── infra                       # 基础依赖配置
├── scripts                     # 启动脚本
└── doc                         # 文档
```

## 步骤 1：启动基础依赖（环境）
执行脚本：
```bash
chmod +x scripts/env-up.sh
./scripts/env-up.sh
```
说明：
- 会启动 MySQL、MongoDB、Redis、Kafka
- 默认账号密码见 `infra/docker-compose.yml`

停止基础依赖：
```bash
chmod +x scripts/env-down.sh
./scripts/env-down.sh
```

## 步骤 2：启动骨架服务
执行脚本：
```bash
chmod +x scripts/start-all.sh
./scripts/start-all.sh
```
说明：
- 服务日志输出到 `logs/` 目录
- 每个服务启动后会生成 `.pid` 文件便于停止

停止全部服务：
```bash
chmod +x scripts/stop-all.sh
./scripts/stop-all.sh
```
