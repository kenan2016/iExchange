# 阶段 3.2：SETNX 幂等演示

## 目标
- 使用 Redis 的 SETNX 实现最简幂等
- 单独放在行情模块，避免与钱包代码交织

## 前置条件
- Redis 已启动（默认 127.0.0.1:6379）
- 行情服务已引入 `spring-boot-starter-data-redis`

## 示例接口
### 地址
`GET /api/market/idempotent/demo`

### 请求参数
- `requestId`：幂等请求ID

### 请求示例
```bash
curl "http://localhost:18085/api/market/idempotent/demo?requestId=demo-1001"
```

## 逻辑说明
1. 使用 `SETNX` 写入幂等键（10 分钟过期）
2. 首次请求返回 `true`，重复请求返回 `false`

## 关键代码
文件：`exchange-market/src/main/java/com/iexchange/market/controller/MarketIdempotentController.java`
- `setIfAbsent` 即 `SETNX`
- 第一次执行返回成功，重复请求直接返回“重复请求”

## 注意事项
- SETNX 仅用于演示幂等思想
- 资金相关业务仍建议 DB 唯一索引兜底
